📈 Les hashtags qui font percer
À lire comme un indice, pas une preuve : les vidéos viennent de nos recherches (mots-clés, comptes), pas de tout TikTok. Plus il y a de recherches, plus le tableau est fiable. Sous chaque vidéo, le pourcentage à côté d'un hashtag est ce même chiffre (en vert : nettement au-dessus de la moyenne).
🔍 Lancer une recherche
Chaque mot est aussi cherché comme hashtag (« argent en ligne » → #argentenligne). Seules les vidéos dans la langue du marché sont gardées. Les mots-clés et les hashtags passent par Apify (≈ 0,004 $ par vidéo lue, pris sur les 5 $ offerts chaque mois ; l'estimation s'affiche ici). Les comptes marchent aussi sans clé. Tout ce qui est trouvé arrive dans « À revoir ».
🔑 Clé Apify
Compte sur apify.com, puis Settings → API & Integrations → Personal API tokens. La clé est vérifiée puis écrite dans le fichier .env de la vidéothèque (ignoré par git) : elle ne part jamais sur GitHub.
